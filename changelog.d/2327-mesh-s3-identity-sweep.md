### Changed
- Agent Mesh S3 (#2327, programme #2225 G8/G14): synthetic-identity fallbacks retired on the research, orchestrator-research, and payments paths. ResearchAgent `runResearch`/`runDiscovery` refuse a request with no explicit `userLogin` instead of running as `"default"`, and `evaluateRun`/`refreshIdeaQuotes` resolve identity from the caller or the run record's recorded owner (declining when neither exists); the orchestrator research path fails closed with no identity (stub helper, publish entry, scheduled-tick route, scheduled trigger); `PaymentsAgent.budgetCheck` requires an explicit `agentId` and fails closed without one — ScheduledAgent now names the orchestrator-attributed spend bucket (`AGENTIC_SPEND_AGENT_ID`) explicitly at both call sites, and the A2A `payments.budget_check` door requires `agentId` like `payments.process` already did.
