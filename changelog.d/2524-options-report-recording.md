### Changed
- Fixed options-report recording (#2524): scan-store summaries now copy XLSX/CSV keys from the scan result and support `updateXlsxKey`/`updateCsvKey` backfills mirroring `updatePdfKey`; the manual options-screen path stamps XLSX/CSV keys onto the saved scan row after generation; serve/orchestrator canonical rows now record per-format statuses and errors and stamp `scanRunId` for the run-summary dedup join; and the HTTP options outcome adapter now carries XLSX/CSV keys and statuses like the event adapter. Canonical backfill (#2528, slice 1) is now also in this change: a redelivery fills missing artifact keys/statuses on an existing inline canonical row, monotonically (failed may upgrade to generated, generated is never overwritten or downgraded), R2-pointer rows are skipped, and a single canonical recorder wrapper `recordUnifiedOptionsRun` is added for options channels. No strategy selection, report content, or delivery behaviour changed. A regenerate button is deliberately not in this change.
