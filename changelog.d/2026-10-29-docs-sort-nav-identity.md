### Docs and Reports scroll + sort, and one identity per left-nav item

- **Docs and Reports** (`?tab=docs`): the page now owns its scroll (`flex: 1 1 auto`, `min-height: 0`, `overflow-y: auto`), so a long run ledger is reachable instead of growing past `.tab-viewport` and being clipped. The table scrolls inside a bounded frame (`max-height: min(68vh, 46rem)`) with a sticky header (`Table` gains `stickyHeader`, reusing the existing `.sticky-head` class). The sort control is a Table-system style (`.ui-table-sort` in `primitives.css`), so bespoke CSS does not grow. Every column is sortable — Date-Time, Run Type, Run Source, PDF, XLSX, CSV, Run ID: header buttons toggle asc/desc, the active `th` carries `aria-sort`, and absent values (unrecorded trigger, no recorded artifact) sort last in both directions. Default order is unchanged (newest first). Pinned by `tests/docs_scroll_sort.test.tsx`; the column pins in `tests/docs_and_reports_panel.test.tsx` and `tests/docs_tab_mount_2078.test.tsx` now read the `.docs-sort-label` span (pin update, §7).
- **Left nav identity:** all 25 nav items now carry a unique icon and a unique badge. New icons: `Approvals` (inbox), `Docs` (file), `Runs` (branch), `Guides` (open book), `Search` (magnifier), `Checkout` (cart), `Assurance` (flask); the order-history `Ledger` glyph becomes a bound book. Duplicate/missing badges are replaced with per-item labels (`Queue`, `DID`, `PDF`, `Hub`, `Trace`, `Partners`, `Earn`, `Yield`, `Daily`, `Feed`, `NLQ`, `Broker`), and `RouteBadgeType` gains `neutral` for informational badges. Pinned by `tests/nav_unique_icons_badges.test.ts`.
