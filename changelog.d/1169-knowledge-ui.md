### Added

- Corpus admin tab (#1169 knowledge UI): a new "Corpus" tab on the Search hub with integrity, sync, and upload sections. Integrity shows the live `GET /knowledge/integrity` report (ok, checkedAt, missing/mismatched/extra bucket keys) plus a per-entry manifest status list (present / missing / mismatched / not-ingested, the last for manifest rows with no recorded hash), with a Download button exporting the report JSON via the shared exporter. Sync offers a manual "Run sync now" trigger (the weekly tick schedule is unchanged) and renders the honest skip shape. Upload posts to the existing corpus route and displays exactly what the API returns (201 fresh vs 200 replay plus key info). The integrity report gains an additive `entries` array; no existing field changed shape or meaning. The manifest is shown as expected documents with status, never as a stored-documents catalog (the corpus has no listing API, by design). The upload file picker is a new `FileInput` ui primitive (token input family, following TextInput/Select), since a raw file input outside components/ui trips the primitive-usage freeze.
