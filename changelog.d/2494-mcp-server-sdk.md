### Changed
- MCP code consolidated under `src/mcps/` (#2494): the OpenAIMP MCP server (the platform tool-catalog server mounted at /mcp and /api/mcp) moved from `src/mcp/` plus `src/permissions/mcpPermissionPorts.ts` to `src/mcps/openaimp/`; the Public MCP client (`PublicMcpClient`, a client of Public.com's hosted MCP server) moved from `src/services/publicMcp.ts` to `src/mcps/public/`; the generic remote-MCP client (`RemoteMcpClient`) moved from `src/services/mcpClient.ts` to `src/mcps/client/`; the x402 options-scanner MCP server moved from `src/services/cloudflareWalletsScanner.ts` to `src/mcps/scanner/`. The server name lives in one constant (`OPENAIMP_MCP_SERVER_NAME`, provisional "openaimp") and is what `initialize` serves.
- The /mcp wire protocol is now served by the SDK handler composition in `src/mcps/openaimp/handler.ts` (the @modelcontextprotocol/sdk `Server` + stateless `WebStandardStreamableHTTPServerTransport` with JSON responses), replacing the hand-rolled JSON-RPC dispatch. Tool catalog, permission gates, identity discipline, error contract and async-job execution carriage are unchanged (protocol-level acceptance battery: `tests/mcp_server_protocol_2494.test.ts`).
