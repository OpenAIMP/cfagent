### Changed
- Ticker WebSocket served by a PortThink agent (#2230): new `TickerAgent extends PortThink` serves `/api/market/quotes/ws` (plus the `/api/market-data/` and `/api/foss/` aliases) with the wire protocol unchanged — subscribe → snapshot, unsubscribe, ping → pong, 5s ticks filtered per connection, cached-first then refreshed, `x-quote-expiry-mode` / `x-quote-stream-provenance` header carriers read at connect. The single shared instance is addressed directly from the Worker so the no-auth, no-audit surface is preserved (routing through `routeAgentRequest` would 401 the public landing page tape); SDK protocol messages are disabled for these plain WebSocket clients. Wiring: `TICKER_AGENT` Durable Object binding + `v11` migration in `wrangler.jsonc`, entrypoint export, `Env` binding type. The old `handleMarketQuotesWebSocket` handler is retained with its pin tests; production traffic moves to the agent. Deploy applies the migration (Ceos lane) and needs a deployed tape check afterwards.
