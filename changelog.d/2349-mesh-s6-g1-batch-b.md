### Added
- Agent Mesh S6 (#2349, programme #2225 G1 batch B): typed orchestrator doors to TradingAgent and ReportAssetAgent, extending the batch-A door/command modules. The chat turn can now create stock/options trade proposals (preview only — pending-approval proposals; the approval door stays unexposed, so no command can execute a trade) and read accounts/positions/quotes through the acting user's own TradingAgent instance, and list/get the user's report assets through their own ReportAssetAgent instance (new `listAssets` metadata method). Seven new turn commands (`propose_stock_trade`, `propose_options_trade`, `get_trading_accounts`, `get_trading_positions`, `get_trading_quote`, `list_report_assets`, `get_report_asset`), each with exactly one MCP scope, all requiring the turn's acting identity and failing closed without one.
