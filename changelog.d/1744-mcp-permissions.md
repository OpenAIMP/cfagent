### Added
- MCP tool permissions (#1744): port-first permission gate (`src/permissions/`) — every one of the 51 registered MCP tools declares exactly one scope (`mcp:read` / `write` / `execute` / `trade` / `payments` / `admin`, completeness-pinned against the live registry), enforced before execution at every choke point (factory, JSON-RPC queued path — a refused call never receives a job receipt — and the agent-turn adapter, which previously bypassed the factory entirely). Tool executions are cryptographically isolated: a fresh 256-bit random key + random id per execution, exact-key open, seal destroyed on completion. Denials return business error `MCP_001`, are audit-logged, and stream as denial events via the #1743 observability port (counts/outcomes only). Default assignment is current behavior (every interactive principal holds every scope, explicitly recorded per #1717 SCOPED DEFAULTS); unknown principals hold nothing. No tool semantics, results, routes, or session auth changed.
