### Added
- Metering enforcement for the single user (issue #2408, Monetization Phase 1.2, sub-issue of #2405): the premium x402/MPP gate now records exactly one usage_event per served paid call (category = paid service id, runId = receipt id) through the existing usage_events port, and the meter is a gate condition — a missing meter or a meter failure refuses with a typed error and serves nothing. The gate checks the tier attribute (stored commercial tier + subscription overlay via resolveEffectiveTier, session traffic only) with a fail-closed default (Free grants nothing by itself; invalid tier or tier-store failure refuses). Tier never bypasses payment in this slice. Ungated/free paths unchanged; no new routes, tables, flags, or UX.
