### Changed

- **Think fleet: OrchestratorAgent on PortThink (#1952, tracker #1951):** `OrchestratorAgent` now extends `PortThink` instead of `Agent`, with its chat turn driven through the foundation Think turn facet (one-shot override + hook-order protocol, lifecycle boot in the adapter) over the unchanged port session. Port hooks and observable behavior are preserved: Judge routing, mas_messages records, route/response audits, and the memory-reset abort epoch all behave as before. The class's domain hooks live under port* names (`portBeforeTurn`/`portOnChatResponse`/`portOnChatError`) because PortThink owns the Think-signature names, and the port-transcript accessors are `getPortMessages`/`addPortMessages`/`runFacetTurn` because Think owns those names with session-backed signatures; `clearMessages` now clears both the port transcript and Think's tree session so a memory reset leaves no pre-reset model context. The gateway model-turn wiring (#1741/#1743) retires with the old runner: Think runs inference with the class's constructed model arm, so chat turns no longer emit gateway observability envelopes.
