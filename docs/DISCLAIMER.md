# Financial Disclaimer

Mirrored from the landing page (`src/client/landing.ts`) so the disclaimer
lives in the docs as well as the product. If the wording changes in either
place, update the other.

> Research outputs are informational, not financial advice. Orders are never
> sent autonomously: each trade is previewed, signed and requires your
> explicit approval, and every action is recorded in an audit ledger. Start
> in the E*TRADE sandbox (TEST) before using production.

Key points:

- Nothing on this platform is financial advice. Screeners, quant grades,
  strategy research, and LLM cross-checks are informational tools.
- No autonomous order execution: every trade proposal requires explicit
  human approval through the confirmation flow before anything is sent to
  the broker.
- Paper-trade / sandbox first: validate any strategy in the E*TRADE sandbox
  (TEST) environment before considering production use.
- Trading involves risk, including the possible loss of principal. Options
  involve additional risks — buyers can lose the entire premium, and
  uncovered writers face potentially unlimited losses.
